# Advanced Training on Microsoft 365 Copilot, Copilot Cowork and Copilot Studio

Embark on a three-day, hands-on journey through low-code Agentic AI development with Copilot Studio and Copilot Cowork, designed for Software Engineers, Solution Architects, and Power Platform Makers. You progress from foundational concepts through tools, orchestration, and ALM, and build agents that solve real business challenges.

You start with the essentials: what agents and Copilots are, how agents work with knowledge, prompts, tools, and the Model Context Protocol (MCP), which harness runs an agent in Copilot Studio, where to build an agent and how Copilot Credits pay for it, and the ready-to-use agents in Copilot: Researcher and Analyst, SharePoint Agents, and Agent Builder. The Copilot Chat basics are pre-class homework.

Copilot Cowork, the agentic experience for everyday knowledge workers, follows. With built-in skills, custom SKILL.md skills, scheduled and event-driven prompts, and plugins, anyone on your team automates recurring workflows without writing code, while human-in-the-loop approvals keep every step under control.

Copilot Studio Basics teaches you to create and configure Standard agents, ground them with knowledge, and build conversations with topics, entities, variables, Power Fx, and Adaptive Cards before you publish to Teams and Copilot. You then give agents tools: prompts with Code Interpreter, Dataverse, connectors, Agent Flows, REST APIs, MCP servers, and Computer Use for apps without an API. Advanced topics add autonomous agents with event triggers, deep reasoning, multi-agent routing, and Microsoft Foundry agents.

Microsoft Copilot harness agents come next, built side by side with the Standard agents of the earlier modules: the unified Build surface and its orchestrator, Agent Skills in the open SKILL.md format, tools, MCP, and the Workflows designer, grounding with Work IQ, Foundry IQ, and Fabric IQ, testing agents with evaluations, and building apps. 

You then publish and maintain what you build: environments and solutions, Microsoft channels, ALM, and source control. Finally you hand the authoring itself to a coding agent: Claude Code with the Copilot Studio plugins clones an agent to `.mcs.yml` files, adds and validates a topic, publishes and tests it, and migrates a Standard agent to the Microsoft Copilot harness, all from the terminal and every change a file you can diff.
